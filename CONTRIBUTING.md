# Contribuir a Dev Visualizer

Gracias por mejorar el atlas. Las contribuciones deben priorizar precisión, claridad y valor educativo.

## Preparación

1. Usa Node.js 24 LTS.
2. Ejecuta `npm install`.
3. Crea una rama descriptiva.
4. Antes de abrir un Pull Request ejecuta `npm run check`.

## Criterios para conceptos

- Empieza por **qué es**, **para qué sirve** y **qué problema resuelve**.
- Explica lo que observa el usuario y lo que ocurre internamente.
- Elige una metáfora visual adecuada; no repitas una composición solo por conveniencia.
- Mantén la animación autónoma, legible y en bucle.
- Respeta `prefers-reduced-motion`.
- Cita documentación oficial cuando el contenido dependa de especificaciones o comportamiento vigente.
- No añadas material con copyright sin permiso.

## Commits

Se recomienda Conventional Commits, por ejemplo: `feat: add WebSocket lifecycle scene`.
