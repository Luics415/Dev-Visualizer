# Aplicar el parche

1. Haz un commit o confirma que tu rama actual está limpia.
2. Copia el contenido de esta carpeta sobre la raíz de `dev-visualizer-starter`.
3. Acepta reemplazar `src/app/page.tsx`, `src/app/globals.css` y `src/components/visual/CodePill.tsx`.
4. Ejecuta:

```bash
npm run lint
npm run build
npm run dev
```

Este parche añade las escenas 6 a 14 y activa los 14 conceptos en la página principal.
