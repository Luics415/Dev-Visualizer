## Interfaz

- Se aplicó la paleta Powder to Vi Arcane al fondo, navegación, textos editoriales y superficies exteriores.

## TypeScript en acción

Nuevo caso integrado de seis etapas:

1. Entrada tipada desde formulario.
2. Contrato estructural `OrderDraft`.
3. Cliente API genérico con entrada y salida relacionadas.
4. Estado mediante unión discriminada.
5. Narrowing por propiedad discriminante.
6. Comprobación de tipos, compilación y ejecución del JavaScript resultante.
