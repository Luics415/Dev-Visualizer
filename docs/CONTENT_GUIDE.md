# Guía editorial y visual

Cada colección debe comenzar con una introducción que responda qué es, para qué sirve, cómo imaginarla y con qué no confundirla.

Cada concepto debe contener:

1. un título preciso,
2. una descripción útil,
3. una metáfora visual alineada con el comportamiento,
4. un estado inicial, una transformación interna y un resultado,
5. animación autónoma en bucle,
6. legibilidad sin depender exclusivamente del color,
7. soporte para movimiento reducido.

Los casos “en acción” deben conectar varias etapas de una misma historia y conservar el apartado **Profundización del caso**. Las referencias a Arcane o League of Legends deben ser sutiles, textuales y no alterar la precisión técnica.
