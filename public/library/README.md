# Adjuntos de la Librería profesional

Los archivos locales se organizan como `/<tema>/<id-del-recurso>/<archivo>`.

Solo se admite un PDF o EPUB cuando su registro en `src/data/professionalLibrary.ts` contiene una licencia de redistribución verificable, su URL de evidencia, tamaño y SHA-256. La accesibilidad pública de un archivo no constituye por sí sola permiso para republicarlo.

Los recursos sin autorización permanecen como fichas con enlaces externos y no deben copiarse a este directorio.
